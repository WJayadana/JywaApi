OpenAPI

Jywa API

Fondasi API untuk platform PPOB Jywa — manajemen user, role, JWT authentication, saldo, dan audit mutasi.

OpenAPI 3.1.0 JWT Auth Express 5 SQLite
Semua endpoint (kecuali /, /health, /api/auth/register, dan /api/auth/login) memerlukan Bearer JWT di header Authorization: Bearer <token>. Token didapat dari register atau login.
🔑 Auth Token — belum ada token —

Token disimpan di localStorage browser. Register atau Login via Try It di bawah untuk auto-save.

200 OK

POST /api/users/:id/balance Ubah saldo user

Perubahan saldo selalu dicatat sebagai mutasi audit. amount adalah integer dalam Rupiah.

Request Body
FieldTypeRequiredDeskripsi
type*enumYadeposit · pembelian · refund
direction*enumYa+ (credit) · - (debit)
amount*integerYaNominal dalam Rupiah (min 1)
notestringTidakKeterangan (max 500 char)
ref_idstringTidakID transaksi terkait (max 100 char)
Contoh: Deposit 50.000
curl -X POST https://jywa.tech/api/users/<id>/balance \
  -H "Authorization: Bearer <token>" \
  -H "content-type: application/json" \
  -d '{
    "type": "deposit",
    "direction": "+",
    "amount": 50000,
    "note": "deposit awal",
    "ref_id": "dep-001"
  }'
201 Created
Response
{
  "user": { ... "balance": 50000 },
  "mutation": {
    "balance_before": 0,
    "balance_after": 50000
  }
}
409 Conflict
Saldo tidak mencukupi
{ "error": "Conflict", "message": "insufficient balance" }

Digiflazz

Provider PPOB · Role: owner

Proxy ke provider Digiflazz untuk cek saldo, daftar harga, tiket deposit, dan transaksi PPOB (prepaid & pascabayar). Semua endpoint kecuali /webhook memerlukan Bearer JWT dan role owner.

GET /api/digiflazz/saldo Cek saldo Digiflazz

Proxy ke endpoint /cek-saldo Digiflazz. Mengembalikan sisa deposit akun.

200 OK
Response
{ "deposit": 500000000 }
GET /api/digiflazz/harga Daftar harga produk

Membaca daftar harga dari JSON cache lokal (tidak hit upstream). Cache otomatis disinkronkan tiap 10 menit secara round-robin prepaid↔pasca. Filter opsional: category, search, status=true. Gunakan endpoint refresh untuk sinkronisasi manual.

Query Parameters
ParamTypeDefaultDeskripsi
cmdenumprepaidprepaid atau pasca
POST /api/digiflazz/harga/refresh Refresh price list manual

Memanggil upstream Digiflazz dan menyimpan seluruh hasil ke JSON cache lokal (data/products.json). Digiflazz membatasi price-list sekitar 5 menit; scheduler otomatis menjalankan refresh setiap 10 menit secara bergantian antara prepaid dan pasca.

Request Body
FieldTypeRequiredDeskripsi
cmdenumTidakprepaid atau pasca; default prepaid
POST /api/digiflazz/deposit Buat tiket deposit

Membuat tiket deposit di Digiflazz. Bank sesuai dengan akun: BCA / MANDIRI / BRI / BNI (Perusahaan) atau Flip / ShopeePay (Perorangan).

Request Body
FieldTypeRequiredDeskripsi
amount*integerYaNominal dalam Rupiah
bank*stringYaBCA / MANDIRI / BRI / BNI / Flip / ShopeePay
owner_name*stringYaNama pemilik rekening pengirim
POST /api/digiflazz/transaksi Transaksi PPOB

Topup prepaid atau inquiry/payment/status pascabayar. commands untuk pascabayar: inq-pasca, pay-pasca, status-pasca. Untuk prepaid, kosongkan commands. Set testing=true untuk transaksi development.

Request Body
FieldTypeRequiredDeskripsi
sku*stringYabuyer_sku_code dari daftar harga
customer_no*stringYaNomor pelanggan / tujuan
ref_id*stringYaID referansi unik Anda
commandsenumTidakinq-pasca · pay-pasca · status-pasca
testingbooleanTidaktrue untuk development
POST /api/digiflazz/webhook Webhook receiver

Endpoint publik yang dilindungi oleh HMAC-SHA1. Header yang diharapkan: X-Hub-Signature: sha1=<hex> dan opsional X-Digiflazz-Event. Signature dihitung dari raw body menggunakan webhook secret.

401 Unauthorized
Signature salah / hilang
{ "error": "Unauthorized", "message": "invalid signature" }
